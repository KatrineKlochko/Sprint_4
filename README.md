# Sprint_4

Краткое описание проекта:  
Этот проект предназначен для автоматизированного
тестирования с использованием Java, Maven и Selenium.

| Технология | Версия |
|------------|--------|
| Java       | 11     |
| JUnit      | 4.13.2 |
| Maven      | 4.0.0  |
| Selenium   | 4.35.0 |


Для запуска тестов используйте команду:
mvn clean test

Для запуска тестов в браузере Firefox используйте команду:
mvn clean test -Dbrowser=firefox
